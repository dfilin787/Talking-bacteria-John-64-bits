# Баги и что с ними делать

Живой список поTalking John (64-bit). Для каждого: симптом → причина → где в коде → что делать.
Отмечено, что уже исправлено, а что осталось / требует проверки на устройстве.

---

## Исправлено (не возвращать)

### 1. Игра крашилась при нажатии кнопок
- **Причина:** `syncGate` делал `queue.sync` с главного потока, пока та же очередь занята обработкой звука → дедлок. Плюс узлы эффектов подключались с жёстким форматом 44.1 кГц, а вход микрофона ставил микшер на 48 кГц — несовпадение роняло граф.
- **Где:** `GameViewController.startReaction`, `SoundBank.init`.
- **Что сделано:** `isPlaying` уже под `deadlinesLock`, `queue.sync` убран; `connect(..., format: nil)` — движок сам согласует формат.
- **Статус:** исправлено, билд зелёный.

### 2. «Микрофон недоступен» при выданном разрешении
- **Причина:** `outputFormat(forBus: 0)` отдавал ноль (вход не поднят), код сразу сдавался.
- **Где:** `VoiceRecorder.beginListening`.
- **Что сделано:** при нуле активируем сессию и берём `inputFormat`, затем фолбэк 44.1 кГц моно; `installTap(format: nil)`, коллектор по первому буферу.
- **Статус:** исправлено.

### 3. «Слушает, но не отвечает» / нужно два триггера
- **Причина:** движок стартовал для эффектов без обращения к `inputNode`; первое обращение добавляло вход в живой граф — tap не качал данные. Плюс коллектор пересоздавался на каждом буфере (проверка читала main-поле), запись = последние 20 мс.
- **Где:** `VoiceRecorder.beginListening` / `consume`.
- **Что сделано:** порядок stop → input/формат → installTap → prepare/start; коллектор создаётся один раз по `tapCollector`.
- **Статус:** исправлено, говорит с первого раза.

### 4. Кивки перебивали говорение
- **Причина:** idle-кивки и `resumeIdle` перезаписывали клип `talk`/`listen`.
- **Где:** `GameViewController.playRandomIdle`, `resumeIdle`, `isFreeForIdle`.
- **Что сделано:** явный флаг `voiceBacteria`; idle/sway/`resumeIdle` не трогают говорящих; снимается только завершением повтора или прямым взаимодействием.
- **Статус:** исправлено.

### 5. Обрезалось начало фразы
- **Причина:** обрезка тишины резала до первого «громкого» участка (первые слоги тише), плюс пауза 0.35 с между повтором и новым слушанием.
- **Где:** `VoiceRecorder.trimSilence`, `handleRecorderState(.idle)`.
- **Что сделано:** начало не режется вообще (только тихий хвост с запасом), пауза убрана.
- **Статус:** исправлено.

### 6. «Даёт тишину» / повторяет воздух
- **Причина:** повторялся любой буфер ≥0.25 с, включая чистую тишину; SoundTouch растягивал тихие края.
- **Где:** `VoiceRecorder.stopListeningAndSpeak`, `trimSilence`.
- **Что сделано:** повтор только при `heardVoice`; обрезка тихих краёв; порог шума поднят.
- **Статус:** исправлено.

### 7. Пончик «ест по 2 раза»
- **Причина:** WAV еды (4.6 с) длиннее клипа (2.7 с), `syncGate` тянул второй проход.
- **Где:** `Reaction.trimSoundToClip`, `GameViewController.startReaction`.
- **Что сделано:** звук еды режется по длине клипа, синк для неё отключён — один проход.
- **Статус:** исправлено.

### 8. Таблетка отскакивала / была одноразовой
- **Причина:** отскок от жертвы и удаление при попадании.
- **Где:** `GameViewController.consumePill`.
- **Что сделано:** таблетка пролетает сквозь бактерий (скорость сохраняется), не одноразовая, исчезает по таймауту бездействия.
- **Статус:** исправлено.

### 9. Шприц: разные анимки у бактерий / «через раз»
- **Причина:** `injectionPool.next()` на каждую бактерию; idle-кивок помечал бактерию busy и хор её пропускал.
- **Где:** `GameViewController.giveInjection`.
- **Что сделано:** одна вариация на всех за укол (чередуется crazy1/crazy2); реакции неэксклюзивны.
- **Статус:** исправлено.

### 10. Кнопки мелкие / бактерии не под кнопками / разный размер
- **Где:** `applyLayout`, `bacteriaField`, `placeBacteria`.
- **Что сделано:** кнопки `max(96*scale,84)` + `setBackgroundImage`; поле на всю ширину; единый `bacteriaDesignHeight`.
- **Статус:** исправлено.

## Осталось / требует проверки на устройстве

### A. Порог голоса может быть туговат для шёпота
- **Симптом:** тихую речь не ловит, либо шум всё ещё цепляет.
- **Где:** `VoiceRecorder.Settings.noiseGate` (сейчас 0.030), `silenceTimeout` (1.0 с).
- **Что делать:** подстроить одну цифру под реальный микрофон: шёпот не ловится → 0.02; шум цепляет → 0.04. Менять только `noiseGate`, не логику.

### B. Гонка `isCapturing`/`heardVoice` между потоками
- **Симптом:** формально UB (bool пишется на main, читается на аудио-потоке). На практике безвредно, но лучше закрыть.
- **Где:** `VoiceRecorder` (`captureLock` уже есть для `isCapturing`/`heardVoice`).
- **Что делать:** убедиться, что все чтения/записи этих полей идут через lock; `level` пишется на main из аудио-колбэка — тоже под lock или атомик.

### C. `SampleCollector` читает только первый канал
- **Симптом:** если вход стерео, правый канал игнорируется (моно-сведение уже есть в `mono()`, так что обычно ок).
- **Где:** `SampleCollector.append`, `VoiceRecorder.consume`.
- **Что делать:** ничего, пока `mono()` отрабатывает; если появится стерео-вход без сведения — добавить усреднение каналов.

### D. Повтор голоса не прерывается кнопками предметов
- **Симптом:** во время `speaking` шприц/пончик могут не сработать, если бактерия занята голосом.
- **Где:** `handleRecorderState(.speaking)`, `perform` (guard `isBacteriaBusy`).
- **Что делать:** решить продуктовое поведение: либо предметы прерывают повтор (вызвать `recorder.stopSpeaking()` + `interruptVoice`), либо оставить как есть (голос важнее). Сейчас говорение не блокирует ввод, но `talkers` помечены `voiceBacteria`, а не `busy`, так что предметы должны проходить — проверить на устройстве.

### E. Watchdog входа убран — первый цикл может молчать на холодном старте
- **Симптом:** изредка первый заход после запуска не слышит (граф не пересобран).
- **Где:** `VoiceRecorder.beginListening`.
- **Что делать:** если воспроизведётся — вернуть мягкий重试: при отсутствии сэмплов через ~1 с один раз пересобрать граф (stop→tap→start), но без гонки на флаге (использовать локальную переменную, захваченную в tap, и проверять её на audio-очереди, не на main).
