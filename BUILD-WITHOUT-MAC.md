# Сборка без Mac

Xcode существует только под macOS, локально на Windows собрать iOS-приложение нельзя.
Но сам Mac для этого не нужен — сборка уезжает на чужую машину.

## Вариант 1. GitHub Actions — бесплатно, ничего не устанавливать

В репозитории уже лежит `.github/workflows/build.yml`. Раннер `macos-15` даёт
Xcode 16.4 и iPhone SDK; пайплайн генерирует проект XcodeGen'ом, собирает arm64,
проверяет `lipo -info` и складывает IPA в артефакты.

Что сделать один раз:

1. Создать **приватный** репозиторий на GitHub (арт Outfit7 — не для публики).
2. Запушить проект:
   ```bash
   cd C:\Users\POKOYO\Projects\TalkingJohn
   git init
   git add .
   git commit -m "Talking John: 64-битная пересборка"
   git branch -M main
   git remote add origin https://github.com/<твой-логин>/talking-john.git
   git push -u origin main
   ```
3. Push запускает сборку сам. Через 5–10 минут: вкладка **Actions** → последний
   запуск → **Artifacts** → `TalkingJohn-build` → внутри `TalkingJohn-unsigned.ipa`.

Лимит бесплатного тарифа — 2000 минут в месяц, macOS считается с коэффициентом 10,
то есть примерно 200 минут macOS-сборок. Одна сборка этого проекта — 3–6 минут.
Хватит на несколько десятков сборок в месяц.

Первый прогон может упасть на компиляции: Swift написан без компилятора под рукой,
и Xcode найдёт то, что статические проверки не видят. Лог `xcodebuild.log`
приходит в артефактах вместе с IPA — присылай его, правлю по нему.

## Вариант 2. Подписанная сборка в том же пайплайне

Unsigned IPA нельзя просто поставить на iPhone — нужна подпись. Два пути:

**Sideloadly / AltStore / TrollStore** — переподписывают unsigned IPA твоим Apple ID
прямо с Windows. Бесплатно, но подпись живёт 7 дней (потом переподписать), и на
устройство ставится максимум 3 таких приложения. TrollStore ставит навсегда, но
работает только на определённых версиях iOS с уязвимостью CoreTrust.

**Сертификат в CI** — если есть Apple Developer Program ($99/год), пайплайн умеет
подписывать сам. Запуск вручную: Actions → Build IPA → Run workflow → галочка
`signed`. Нужны секреты репозитория:

| Секрет | Что это |
|---|---|
| `IOS_P12_BASE64` | сертификат .p12 в base64 |
| `IOS_P12_PASSWORD` | пароль от .p12 |
| `IOS_PROVISION_BASE64` | .mobileprovision в base64 |
| `APPLE_TEAM_ID` | Team ID из аккаунта разработчика |

Закодировать на Windows:
```bash
certutil -encode cert.p12 cert.b64
```
(убрать строки `-----BEGIN/END CERTIFICATE-----` и склеить в одну строку), либо
```bash
python -c "import base64;print(base64.b64encode(open('cert.p12','rb').read()).decode())"
```

## Вариант 3. Арендованный Mac

Если хочется Xcode руками — почасовая аренда:
- **MacStadium / MacinCloud** — от $1/час, полный доступ к macOS по VNC.
- **Scaleway Mac mini M1** — около €0.1/час, минимум 24 часа.
- **AWS EC2 Mac** — дорого и минимум сутки, для этого не годится.

Смысл есть, если планируешь часто править UI и смотреть результат вживую. Для
разовой сборки — переплата, Actions делает то же бесплатно.

## Что НЕ работает

- **Docker с macOS** — лицензия Apple запрещает macOS вне железа Apple, готовых
  образов нет; всё, что предлагается, — серая зона и обычно ломается.
- **Hackintosh в VM** — технически возможно, но долго, хрупко и нарушает EULA.
- **swift на Windows** — Swift там есть, но UIKit и iPhone SDK отсутствуют,
  собрать iOS-приложение нельзя в принципе.
- **Онлайн-компиляторы Swift** — нет UIKit, нет подписи, нет бандла ассетов.
